# shellemu — эмулятор командной оболочки UNIX

Эмулятор командной строки UNIX-подобной ОС с графическим интерфейсом.
Работает с виртуальной файловой системой (VFS), которая загружается из
XML-файла и целиком хранится в памяти. Python 3.10+, tkinter, только
стандартная библиотека.

## Возможности

- Окно с заголовком `Эмулятор - [username@hostname]` (данные реальной ОС),
  приглашение `user@host:/путь$`, история команд на стрелках вверх и вниз.
- Команды `ls`, `cd`, `date`, `tac`, `chown`, `touch`, `vfs-load`, `exit`
  и служебная `vfs-tree`. Сообщения об ошибках в формате UNIX.
- Стартовые скрипты: ввод и вывод показываются как диалог, комментарии `#`.
- VFS из XML (текст и base64), все изменения только в памяти.

## Сборка, запуск, тесты

Сборки нет, нужен только Python 3.10+ с tkinter (входит в установщик
Python для Windows и macOS; в Linux: пакет `python3-tk`).

```
make run                                  # окно эмулятора
make run ARGS="--vfs vfs/deep.xml"        # с VFS
make test                                 # unittest
```

Без `make` (PowerShell):

```
$env:PYTHONPATH="src"
python -m shellemu --vfs vfs\deep.xml --script scripts\emu\all_commands.emu
python -m unittest discover -s tests -v
```

## Параметры командной строки

| Параметр        | Описание                                                  |
|-----------------|-----------------------------------------------------------|
| `--vfs ПУТЬ`    | Путь к XML-файлу VFS                                      |
| `--script ПУТЬ` | Путь к стартовому скрипту                                 |
| `--headless`    | Служебный режим без окна: диалог печатается в консоль; без `--script` команды читаются со стандартного ввода (нужен для скриптов реальной ОС и тестов) |

При запуске печатается отладочный вывод всех параметров (`[debug] ...`).
Коды завершения: 0 — успех (или код из `exit N`), 2 — ошибка параметров
или скрипта. Ошибка загрузки VFS сообщается в окне, работа продолжается
с пустой VFS.

## Стартовый скрипт

Текстовый файл, одна команда в строке. `#` начинает комментарий (в начале
строки или после команды), пустые строки пропускаются. Кавычки группируют
слова (`cd "my dir"`); обратная косая черта не экранирует, поэтому пути
Windows (`vfs-load vfs\deep.xml`) работают как есть. `exit N` завершает
скрипт и эмулятор. Если `exit` нет, после скрипта работа продолжается в
интерактивном режиме.

## Формат VFS

```xml
<vfs owner="root" group="root">
  <dir name="home" owner="alice" mtime="2026-09-01T10:30:00">
    <file name="a.txt">текст файла</file>
    <file name="data.bin" encoding="base64">AAECAwQ=</file>
  </dir>
</vfs>
```

- `<file>`: `encoding="text"` (по умолчанию) или `"base64"` для двоичных данных.
- Необязательные атрибуты: `owner`, `group` (по умолчанию `root`), `mtime`
  (ISO 8601, по умолчанию время загрузки).
- Имена без `/`, не `.` и не `..`, без дубликатов в одном каталоге.

Ошибки загрузки: файл не найден, неверный XML, неверный корневой элемент,
неизвестный элемент, дубликат, нет `name`, неверные base64, дата, кодировка.

Примеры в `vfs/`: `minimal.xml` (минимальный), `files.xml` (несколько
файлов, base64), `deep.xml` (пять уровней вложенности), `broken/*`
(некорректные файлы для проверки ошибок).

## Команды

Пути абсолютные и относительные, с `.` и `..`. Короткие опции
объединяются (`-la`), `--` заканчивает опции.

| Команда | Описание |
|---------|----------|
| `ls [-l] [-a] [путь...]` | Список файлов. `-l` — длинный формат, `-a` — скрытые файлы, `.` и `..`. Несколько каталогов выводятся с заголовками. |
| `cd [путь]` | Смена каталога. Без аргумента — корень VFS, `cd -` — предыдущий каталог. |
| `date [-u] [-R] [-I] [+ФОРМАТ]` | Дата и время. `-u` — UTC, `-R` — RFC 2822, `-I` — дата ISO, `+ФОРМАТ` — шаблон strftime. |
| `tac ФАЙЛ...` | Строки файлов в обратном порядке (как GNU tac). |
| `chown [-R] [-v] ВЛАДЕЛЕЦ[:ГРУППА] ФАЙЛ...` | Смена владельца и/или группы (`:ГРУППА` — только группа). `-R` — рекурсивно, `-v` — подробный вывод. |
| `touch [-c] ФАЙЛ...` | Создаёт пустой файл (владелец — текущий пользователь) или обновляет время изменения. `-c` — не создавать. |
| `vfs-load ПУТЬ` | Загружает новую VFS с диска вместо текущей, каталог сбрасывается в `/`. При ошибке текущая VFS сохраняется. |
| `exit [код]` | Выход. |
| `vfs-tree` | Служебная: дерево текущей VFS. |

Все изменения (`chown`, `touch`, `vfs-load`) происходят только в памяти:
XML-файл на диске никогда не изменяется.

Упрощения: права в `ls -l` условные (`drwxr-xr-x` и `-rw-r--r--`), число
ссылок всегда 1, строки `total` нет, прав доступа нет (`chown` может
менять кто угодно), время — местное время ОС.

## Примеры

```
$ python -m shellemu --headless --vfs vfs/deep.xml
root@vm:/$ ls -l /home/alice
drwxr-xr-x 1 alice root  0 Oct 28 10:37 projects
-rw-r--r-- 1 alice root 99 Oct 28 10:37 todo.txt
root@vm:/$ cd /var/log
root@vm:/var/log$ tac syslog
третья запись
вторая запись
первая запись
root@vm:/var/log$ touch new.txt
root@vm:/var/log$ chown -v bob:staff new.txt
changed ownership of 'new.txt' from root:root to bob:staff
root@vm:/var/log$ cd /nope
cd: /nope: No such file or directory
root@vm:/var/log$ exit
```

## Скрипты

Скрипты эмулятора (`scripts/emu/`):

| Файл | Что проверяет |
|------|---------------|
| `basic.emu` | Комментарии, кавычки, ошибки ввода, `exit` (этап 2) |
| `exit_code.emu` | Код возврата `exit 7` |
| `vfs_demo.emu` | Команды этапов 1–3 с разными VFS |
| `core_commands.emu` | `ls`, `cd`, `tac`, `date`: все режимы и ошибки |
| `modify_vfs.emu` | `touch`, `chown`, `vfs-load`: все режимы и ошибки |
| `all_commands.emu` | Сводный пример всех команд |

Скрипты реальной ОС (Linux/macOS `.sh`, Windows `.bat`) запускают эмулятор
с разными параметрами в режиме `--headless`:

- `scripts/run_stage2.*` — все параметры командной строки, ошибки;
- `scripts/run_stage3.*` — минимальная, средняя и вложенная VFS, ошибки загрузки;
- `scripts/run_stage5.*` — стартовые скрипты этапов 4 и 5.

## Структура

```
src/shellemu/   parser, shell, commands (cmd_nav, cmd_text, cmd_fs),
                vfs, vfs_xml, script, dialog, cli, gui
tests/          unittest-тесты (логика; GUI проверяется с подменой tkinter)
vfs/            примеры VFS
scripts/        скрипты реальной ОС и скрипты эмулятора
```
