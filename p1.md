## Задача 3

Написать программу banner средствами bash для вывода текстов, как в следующем примере (размер баннера должен меняться!):

```
[root@localhost ~]# ./banner "Hello from RTU MIREA!"
+-----------------------+
| Hello from RTU MIREA! |
+-----------------------+
```

Перед отправкой решения проверьте его в ShellCheck на предупреждения.
---
### Решение
nano banner  
```
# Проверяем, ввел ли пользователь текст
if [ -z "$1" ]; then
    echo "Ошибка: введите текст в кавычках!" >&2
    exit 1
fi

text="$1"
text_len=${#text}

# Создаем линию из дефисов нужной длины
dashes=$(printf '%*s' "$((text_len + 2))" | tr ' ' '-')

# Рисуем баннер
echo "+${dashes}+"
echo "| ${text} |"
echo "+${dashes}+"

```

chmod +x banner - делаем файл исполняемым  
./banner "Hello from RTU MIREA"

---
### Результат
```
+----------------------+
| Hello from RTU MIREA |
+----------------------+
```

## Задача 5

Написать программу для регистрации пользовательской команды (правильные права доступа и копирование в /usr/local/bin).

Например, пусть программа называется reg:

```
./reg banner
```

В результате для banner задаются правильные права доступа и сам banner копируется в /usr/local/bin.
---
### Решение
nano reg  
```
#!/bin/bash

# 1. Проверяем, передан ли аргумент (имя файла)
if [ -z "$1" ]; then
    echo "Ошибка: укажите имя программы для регистрации!" >&2
    echo "Пример: $0 banner" >&2
    exit 1
fi

# Переменная для удобства
TARGET_FILE="$1"

# 2. Проверяем, существует ли вообще такой файл в текущей папке
if [ ! -f "$TARGET_FILE" ]; then
    echo "Ошибка: файл '$TARGET_FILE' не найден в текущей директории!" >&2
    exit 1
fi

# 3. Задаем правильные права доступа (делаем исполняемым для всех: rwxr-xr-x)
chmod 755 "$TARGET_FILE"
echo "Права доступа для '$TARGET_FILE' успешно изменены на 755 (исполняемый)."

# 4. Копируем файл в /usr/local/bin
# Используем sudo, так как обычный пользователь не имеет прав на запись в эту папку
echo "Копирование в /usr/local/bin... (может потребоваться пароль sudo)"
sudo cp "$TARGET_FILE" /usr/local/bin/

# 5. Проверяем, успешно ли прошло копирование
if [ $? -eq 0 ]; then
    echo "Успех! Программа '$TARGET_FILE' зарегистрирована. Теперь её можно запускать из любого места."
else
    echo "Ошибка при копировании файла в /usr/local/bin!" >&2
    exit 1
fi
```
chmod +x reg  
./reg banner  
---
### Результат
программа banner будет работать в любом месте
