## Задача 5

Написать программу для регистрации пользовательской команды (правильные права доступа и копирование в /usr/local/bin).

Например, пусть программа называется reg:

```
./reg banner
```

В результате для banner задаются правильные права доступа и сам banner копируется в /usr/local/bin.
---
### Решение
nano reg  
```
#!/bin/bash

# 1. Проверяем, передан ли аргумент (имя файла)
if [ -z "$1" ]; then
    echo "Ошибка: укажите имя программы для регистрации!" >&2
    echo "Пример: $0 banner" >&2
    exit 1
fi

# Переменная для удобства
TARGET_FILE="$1"

# 2. Проверяем, существует ли вообще такой файл в текущей папке
if [ ! -f "$TARGET_FILE" ]; then
    echo "Ошибка: файл '$TARGET_FILE' не найден в текущей директории!" >&2
    exit 1
fi

# 3. Задаем правильные права доступа (делаем исполняемым для всех: rwxr-xr-x)
chmod 755 "$TARGET_FILE"
echo "Права доступа для '$TARGET_FILE' успешно изменены на 755 (исполняемый)."

# 4. Копируем файл в /usr/local/bin
# Используем sudo, так как обычный пользователь не имеет прав на запись в эту папку
echo "Копирование в /usr/local/bin... (может потребоваться пароль sudo)"
sudo cp "$TARGET_FILE" /usr/local/bin/

# 5. Проверяем, успешно ли прошло копирование
if [ $? -eq 0 ]; then
    echo "Успех! Программа '$TARGET_FILE' зарегистрирована. Теперь её можно запускать из любого места."
else
    echo "Ошибка при копировании файла в /usr/local/bin!" >&2
    exit 1
fi
```
chmod +x reg  
./reg banner  
---
### Результат
программа banner будет работать в любом месте
## Задача 6

Написать программу для проверки наличия комментария в первой строке файлов с расширением c, js и py.

### Решение  

```
# Перебираем файлы с расширениями .c, .js, .py в текущей директории
for file in *.{c,js,py}; do
    # Проверяем, существует ли файл
    if [ ! -f "$file" ]; then
        continue
    fi

    # Читаем самую первую строку файла
    first_line=$(head -n 1 "$file")

    # Проверяем, начинается ли строка с символов комментария
    if [[ "$first_line" =~ ^# ]] || [[ "$first_line" =~ ^// ]] || [[ "$first_line" =~ ^/\* ]]; then
        echo "Файл '$file': Комментарий в первой строке найден."
    else
        echo "Файл '$file': Комментарий в первой строке отсутствует!"
    fi
done
```
## Задача 7

Написать программу для нахождения файлов-дубликатов (имеющих 1 или более копий содержимого) по заданному пути (и подкаталогам).

### Решение
```
path="$1"

if [ -z "$path" ]
then
        echo "Укажите путь"
        exit 1
fi
 
# Определяем путь к временному файлу, куда запишем список всех найденных файлов
list="/tmp/files.txt"
 
# Находим все обычные файлы (-type f) по указанному пути (включая подпапки)
find "$path" -type f > "$list"
 
n=0

#Внешний цикл проходится по всем файлам в папке, внутренний по всем оставшимся и сравнивает с выбранным файлом со внешнего цикла.
while IFS= read -r file1
do
        n=$((n+1))
        
        m=0
 
 
        # Переменная file2 хранит путь ко второму файлу, с которым мы сравниваем file1.
        while IFS= read -r file2
        do
                # Увеличиваем счетчик текущей строки внутреннего цикла
                m=$((m+1))

                #Пропускаем текущий файл.
                if [ "$m" -le "$n" ]
                then
                        continue
                fi

                # Сравниваем содержимое двух файлов.
                if cmp -s "$file1" "$file2"
                then
                        echo "Дубликаты: $file1 и $file2"
                fi
        done < "$list"
done < "$list"
 
#удаляем временный файл, чтобы не засорять систему
rm "$list"
```


## Задача 8

Написать программу, которая находит все файлы в данном каталоге с расширением, указанным в качестве аргумента и архивирует все эти файлы в архив tar.

### Решение
```
#!/bin/bash

# Проверяем наличие двух аргументов
if [ -z "$1" ] || [ -z "$2" ]; then
    echo "Ошибка: требуется указать расширение и директорию!" >&2
    echo "Пример: $0 txt /my/folder" >&2
    exit 1
fi

EXT="$1"
DIR="$2"
ARCHIVE_NAME="archive_${EXT}.tar"

# Проверяем, существует ли указанная директория
if [ ! -d "$DIR" ]; then
    echo "Ошибка: директория '$DIR' не существует" >&2
    exit 1
fi

echo "Поиск файлов с расширением *.$EXT в '$DIR'..."

# Ищем файлы только в указанной директории и подпапках
find "$DIR" -type f -name "*.$EXT" > /tmp/found_files.txt

# Проверяем, нашли ли мы хоть один файл
if [ ! -s /tmp/found_files.txt ]; then
    echo "Файлы с расширением *.$EXT не найдены. Архивация отменена."
    rm -f /tmp/found_files.txt
    exit 0
fi

# Архивируем найденные файлы
echo "Создание архива $ARCHIVE_NAME..."
tar -cvf "$ARCHIVE_NAME" -T /tmp/found_files.txt

echo "Успех! Архив $ARCHIVE_NAME успешно создан."
rm -f /tmp/found_files.txt
```

## Задача 10

Написать программу, которая выводит названия всех пустых текстовых файлов в указанной директории. Директория передается в программу параметром. 

### Решение
```
#!/bin/sh
 
dir="$1"
 
if ! [ -d "$dir" ]
then
        echo "Директортия не найдена"
        exit 1
fi
 
for file in "$dir"/*
do
        #! -s (если нет размера, то выводим файл)
        if [ -f "$file" ] && [ ! -s "$file" ]
        then
                echo "$file"
        fi
done
```
